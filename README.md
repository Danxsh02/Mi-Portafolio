### About

This is my personal portfolio: a single place to show who I am, what I do, the tools I work with and the projects I have built. It is designed as a visual narrative, from the hero to the contact section, where every part has a purpose.

- **Hero:** an interactive 3D wireframe sphere drawn on canvas that reacts to the cursor.
- **About & Expertise:** my background and the six disciplines I work in: web, Unity and interactive, UI/UX, audio, video/motion/3D, and databases/backend.
- **Selected work:** an automatic carousel of projects with side controls, drag and swipe support, and a detailed view for each one, including a visual walkthrough gallery.
- **Audio & Video:** a space for sound design, editing and motion pieces.
- **Toolkit:** the technologies I use, organized by discipline.
- **Contact:** the quickest way to reach me.

### Design & engineering notes

- Fully responsive. Layouts, typography and navigation are adapted for desktop, laptop, tablet and mobile instead of just scaling down.
- Dark, restrained visual identity with a single lime accent, and subtle geometric motion in the background.
- Built with plain HTML, CSS and JavaScript. No frameworks or build step.
- Performance-minded: canvas animations pause when off-screen, and carousels only move when visible.
- Accessible: semantic markup, ARIA labels, native dialogs, visible focus states and support for `prefers-reduced-motion`.
- Bilingual interface (English / Spanish).

### Tech stack

HTML5 · CSS3 · Vanilla JavaScript · Canvas API · Google Fonts (Unbounded, Plus Jakarta Sans)

## Español

### Sobre este proyecto

Es mi portafolio personal: un solo lugar para mostrar quién soy, qué hago, con qué herramientas trabajo y qué proyectos he desarrollado. Está pensado como una narrativa visual en la que cada sección tiene una razón de existir.

### Contenido

- **Hero:** una esfera 3D de alambre dibujada en canvas que reacciona al cursor.
- **Sobre mí y Áreas de trabajo:** mi perfil y las seis disciplinas en las que trabajo.
- **Proyectos:** carrusel automático con controles laterales, arrastre y deslizamiento táctil, y una ficha detallada por proyecto con recorrido visual.
- **Audio y Video:** espacio para diseño sonoro, edición y motion.
- **Herramientas:** las tecnologías que uso, organizadas por disciplina.
- **Contacto:** la forma más rápida de escribirme.

### Notas de diseño e ingeniería

- Responsive real para escritorio, portátil, tablet y móvil, con composiciones adaptadas a cada tamaño.
- Identidad oscura y sobria con un único acento lima y movimiento geométrico sutil de fondo.
- HTML, CSS y JavaScript puros, sin frameworks ni paso de compilación.
- Animaciones optimizadas, accesibilidad y soporte de `prefers-reduced-motion`.
- Interfaz bilingüe (inglés / español).
